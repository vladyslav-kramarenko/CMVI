Method and applicability

Trapezoidal rule

In=h[f(a)2+∑i=1n−1f(a+ih)+f(b)2]

For sufficiently smooth f, the composite trapezoidal rule has order p = 2.

Use a positive target error to refine the grid automatically, or enter 0 to retain the requested grid.

Worked examples

Basic 1

∫₀¹ x² dx; n = 4

Expected result: I₄ = 0.34375; I = 1/3

Calculation steps
  1. h = 1/4; f(0) = 0; f(1/4) = 1/16; f(1/2) = 1/4; f(3/4) = 9/16; f(1) = 1
  2. I₄ = (1/4)(0 + 1/16 + 1/4 + 9/16 + 1/2) = 11/32
  3. I₈ = 43/128; |I₈ − I₄|/3 = 1/384
  4. |I₄ − 1/3| = 1/96

Accuracy and common pitfalls

For f ∈ C²[a,b], the composite rule has an error bound (b−a)h² max|f″|/12. Runge estimates and independent grids do not prove this derivative bound.
