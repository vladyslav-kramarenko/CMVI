Метод Гауса — Зейделя

Досліджуйте послідовні оновлення, умови збіжності та історію нев’язки лінійних систем.

Калькулятор

Завантажте задачу й натисніть «Розв’язати», щоб побачити кроки. Деякі поглиблені приклади навмисно не розв’язуються цим методом або розбігаються.

Приклад завантажено. Натисніть «Розв’язати».

Результати

Звіт про розв’язання

Розв’язані приклади

Базовий 1

4x₁ + x₂ = 6; 2x₁ + 3x₂ = 8; x⁽⁰⁾ = (0, 0)

Еталонний результат: x ≈ (1, 2)

Кроки обчислення
  1. x₁⁽ᵏ⁺¹⁾ = (6 − x₂⁽ᵏ⁾)/4; x₂⁽ᵏ⁺¹⁾ = (8 − 2x₁⁽ᵏ⁺¹⁾)/3
  2. x⁽⁰⁾ = (0, 0) → x⁽¹⁾ = (1.5, 5/3)
  3. x⁽²⁾ = (13/12, 35/18)
  4. |4| > |1|; |3| > |2|; x⁽ᵏ⁾ → (1, 2)

Джерело: Авторська задача

Академічний 2

2x − y = 3; x + 3y = 1; x⁽⁰⁾ = (1, −1); k = 3

Еталонний результат: x⁽³⁾ = (17/12, −5/36)

Кроки обчислення
  1. x⁽ᵏ⁺¹⁾ = (3 + y⁽ᵏ⁾)/2; y⁽ᵏ⁺¹⁾ = (1 − x⁽ᵏ⁺¹⁾)/3
  2. x⁽¹⁾ = (1, 0); x⁽²⁾ = (3/2, −1/6)
  3. x⁽³⁾ = (17/12, −5/36)

Джерело: Durham University · MATH1551, 1.13

Поглиблений 3

x + 2y = 3; 2x + y = 3; k = 8

Еталонний результат: x⁽¹⁾ = (3, −3); x⁽²⁾ = (9, −15)

Очікується досягнення ліміту, а не збіжність.

Джерело: Авторська задача

Точність і типові помилки

Нові компоненти використовуються одразу. Перестановка рівнянь може змінити збіжність.
