Метод Гауса

Розв’язуйте системи лінійних рівнянь методом Гауса — Жордана з вибором провідного елемента та перевіркою нев’язки.

Калькулятор

Завантажте задачу й натисніть «Розв’язати», щоб побачити кроки. Деякі поглиблені приклади навмисно не розв’язуються цим методом або розбігаються.

Приклад завантажено. Натисніть «Розв’язати».

Метод і умови застосовності

Метод Гаусса — Жордана

[A|b]→[I|x]

Квадратна система Ax = b має єдиний розв’язок, якщо A невироджена.

Частковий вибір головного елемента зменшує деякі похибки округлення, але не усуває погану обумовленість.

Результати

Звіт про розв’язання

Розв’язані приклади

Базовий 1

4x₁ + x₂ = 6; 2x₁ + 3x₂ = 8

Еталонний результат: x = (1, 2)

Кроки обчислення
  1. [4, 1 | 6; 2, 3 | 8] → R₂ − ½R₁ → [4, 1 | 6; 0, 2.5 | 5]
  2. R₂ / 2.5 → [0, 1 | 2]
  3. R₁ − R₂ → [4, 0 | 4] → R₁ / 4 → [1, 0 | 1]
  4. Ax − b = (0, 0)

Джерело: Авторська задача

Академічний 2

x + 3y = 7; 3x + 4y = 11

Еталонний результат: x = 1; y = 2

Кроки обчислення
  1. R₂ ← R₂ − 3R₁ → −5y = −10
  2. y = 2; x = 7 − 3y = 1

Джерело: Los Angeles City College · LibreTexts §2.2

Поглиблений 3

x + 2y = 3; 2x + 4y = 7

Еталонний результат: rank(A) = 1; rank([A|b]) = 2

Кроки обчислення
  1. R₂ ← R₂ − 2R₁ → 0 = 1

Очікується відмова: система несумісна, єдиного розв’язку немає.

Джерело: Авторська задача

Точність і типові помилки

Мала нев’язка не гарантує точності за поганої обумовленості; порівнюйте зворотну похибку та число обумовленості.
