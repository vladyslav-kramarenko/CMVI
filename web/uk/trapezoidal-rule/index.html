Метод трапецій

Наближено обчислюйте визначені інтеграли складеною формулою трапецій з уточненням сітки й оцінкою Рунге.

Калькулятор

Завантажте задачу й натисніть «Розв’язати», щоб побачити кроки. Деякі поглиблені приклади навмисно не розв’язуються цим методом або розбігаються.

Приклад завантажено. Натисніть «Розв’язати».

Метод і умови застосовності

Метод трапецій

In=h[f(a)2+∑i=1n−1f(a+ih)+f(b)2]

Для достатньо гладкої f складена формула трапецій має порядок p = 2.

Задайте додатну цільову похибку для автоматичного уточнення сітки або 0 для збереження вихідної сітки.

Результати

Звіт про розв’язання

Розв’язані приклади

Базовий 1

∫₀¹ x² dx; n = 4

Еталонний результат: I₄ = 0.34375; I = 1/3

Кроки обчислення
  1. h = 1/4; f(0) = 0; f(1/4) = 1/16; f(1/2) = 1/4; f(3/4) = 9/16; f(1) = 1
  2. I₄ = (1/4)(0 + 1/16 + 1/4 + 9/16 + 1/2) = 11/32
  3. I₈ = 43/128; |I₈ − I₄|/3 = 1/384
  4. |I₄ − 1/3| = 1/96

Джерело: Авторська задача

Академічний 2

∫₁² x³ dx; n = 4

Еталонний результат: I₄ = 3.796875; I = 3.75

Кроки обчислення
  1. h = 1/4
  2. I₄ = ¼[½ + (5/4)³ + (3/2)³ + (7/4)³ + 4]

Джерело: University of Waterloo · Topic 13.2

Академічний 3

∫₁² x³ dx; n = 8

Еталонний результат: I₈ = 3.76171875

Кроки обчислення
  1. h = 1/8; I₈ = 3.76171875
  2. |I₈ − I₄|/3 = 0.01171875

Джерело: University of Waterloo · Topic 13.2

Поглиблений 4

∫₀¹ cos(128πx) dx; n₀ = 4; ε = 10⁻⁶

Еталонний результат: I = 0; |Iₙ| ≤ 10⁻⁶

Початкові двійкові сітки маскують коливання; незалежна сітка виявляє розбіжність.

Джерело: Авторська задача

Точність і типові помилки

Для f ∈ C²[a,b] межа похибки — (b−a)h² max|f″|/12. Оцінка Рунге й незалежні сітки не доводять межу похідної.
