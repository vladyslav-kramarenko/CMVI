Інтерполяція Лагранжа

L(x)=∑iyi∏j≠ix−xjxi−xj

Різні вузли x визначають єдиний поліном степеня не вище n − 1. Екстраполяція та високий степінь можуть бути ненадійними.

Результати

Звіт про розв’язання

Приклад розв’язання

(0, 0), (1, 1), (2, 4) → L(x) = x² → L(1.5) = 2.25

Кроки обчислення

  1. ℓ₀(x) = (x − 1)(x − 2)/2; ℓ₁(x) = −x(x − 2); ℓ₂(x) = x(x − 1)/2
  2. L(x) = 0·ℓ₀(x) + ℓ₁(x) + 4ℓ₂(x)
  3. L(x) = −x(x − 2) + 2x(x − 1) = x²
  4. L(1.5) = 2.25

Точність і типові помилки

Барицентрична форма краща за розгорнуті коефіцієнти, особливо для великих чи близьких вузлів. Вона не усуває осциляцій та ненадійної екстраполяції.
