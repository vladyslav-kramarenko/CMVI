Калькулятор

Метод і умови застосовності

Інтерполяція Лагранжа

L(x)=∑iyi∏j≠ix−xjxi−xj

Різні вузли x визначають єдиний поліном степеня не вище n − 1. Екстраполяція та високий степінь можуть бути ненадійними.

Результати

Звіт про розв’язання

Розв’язані приклади

Базовий 1

(0, 0), (1, 1), (2, 4)

Еталонний результат: L(x) = x²; L(1.5) = 2.25

Кроки обчислення
  1. ℓ₀(x) = (x − 1)(x − 2)/2; ℓ₁(x) = −x(x − 2); ℓ₂(x) = x(x − 1)/2
  2. L(x) = 0·ℓ₀(x) + ℓ₁(x) + 4ℓ₂(x)
  3. L(x) = −x(x − 2) + 2x(x − 1) = x²
  4. L(1.5) = 2.25

Джерело: Авторська задача

Академічний 2

(0, 0), (1, 1), (3, 2); x = 2

Еталонний результат: L(x) = (7x − x²)/6; L(2) = 5/3

Кроки обчислення
  1. L(x) = −x(x − 3)/2 + x(x − 1)/3
  2. L(x) = (7x − x²)/6

Джерело: P. Staab · Numerical Analysis §4.2

Поглиблений 3

(0, 0), (1, 1), (3, 2); x = 4

Еталонний результат: L(4) = 2

Точка поза інтервалом вузлів; екстраполяція не завжди надійна.

Джерело: Авторська задача

Точність і типові помилки

Барицентрична форма краща за розгорнуті коефіцієнти, особливо для великих чи близьких вузлів. Вона не усуває осциляцій та ненадійної екстраполяції.
