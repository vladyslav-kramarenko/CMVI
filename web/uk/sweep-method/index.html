Метод прогонки (алгоритм Томаса)

Розв’язуйте лінійні крайові задачі другого порядку скінченними різницями з умовами Робіна та таблицями прогонки.

Калькулятор

Завантажте задачу й натисніть «Розв’язати», щоб побачити кроки. Деякі поглиблені приклади навмисно не розв’язуються цим методом або розбігаються.

Приклад завантажено. Натисніть «Розв’язати».

Метод і умови застосовності

Метод прогонки (алгоритм Томаса)

liyi−1+diyi+uiyi+1=ri

Дискретизована тридіагональна система має допускати ненульові провідні елементи прогонки. На межах використовуються односторонні різниці першого порядку.

Результати

Звіт про розв’язання

Розв’язані приклади

Базовий 1

y″ = −2; y(0) = y(1) = 0

Еталонний результат: y = (0, 1/4, 0)

Кроки обчислення
  1. n = 2; h = 1/2; y₀ = y₂ = 0
  2. 4y₀ − 8y₁ + 4y₂ = −2
  3. y₁ = 1/4; (y₀, y₁, y₂) = (0, 1/4, 0)
  4. y(x) = x(1 − x); y″ = −2

Джерело: Авторська задача

Академічний 2

T″ − 166(T − 293) = 0; T(0) = 473; T(0.1) = 293; n = 5

Еталонний результат: T ≈ (473, 424.455861, 384.640390, 350.909842, 321.024507, 293) K

Кроки обчислення
  1. h = 0.02; 2500Tᵢ₋₁ − 5166Tᵢ + 2500Tᵢ₊₁ = −48638
  2. T₀ = 473; T₅ = 293

Задача з TU Delft; еталонні вузлові значення незалежно обчислені для цієї дискретизації.

Джерело: TU Delft · MUDE §2.9

Поглиблений 3

y″ = 0; y′(0) + 2y(0) = 1; y(1) = 0; n = 2

Еталонний результат: y(x) = 1 − x; d₀ = 0

Кроки обчислення
  1. y(x) = 1 − x → y′(0) + 2y(0) = 1
  2. d₀ = 2 − 1/h = 0

Крайова задача розв’язна, але прогонка без вибору провідного елемента не може тривати.

Джерело: Авторська задача

Точність і типові помилки

Нульовий провідний елемент можливий навіть у розв’язній крайовій задачі. Дискретні нев’язки та різниці сіток вимірюють різні аспекти точності.
