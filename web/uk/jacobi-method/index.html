Метод Якобі

Розв’язуйте системи методом Якобі з перевіркою діагональної переваги та графіком збіжності.

Калькулятор

Завантажте задачу й натисніть «Розв’язати», щоб побачити кроки. Деякі поглиблені приклади навмисно не розв’язуються цим методом або розбігаються.

Приклад завантажено. Натисніть «Розв’язати».

Метод і умови застосовності

Метод Якобі

xi(k+1)=bi−∑j≠iaijxj(k)aii

Усі діагональні елементи мають бути ненульовими. Строга діагональна перевага за рядками — достатня, але не необхідна умова збіжності.

Результати

Звіт про розв’язання

Розв’язані приклади

Базовий 1

4x₁ + x₂ = 6; 2x₁ + 3x₂ = 8; x⁽⁰⁾ = (0, 0)

Еталонний результат: x ≈ (1, 2)

Кроки обчислення
  1. x₁⁽ᵏ⁺¹⁾ = (6 − x₂⁽ᵏ⁾)/4; x₂⁽ᵏ⁺¹⁾ = (8 − 2x₁⁽ᵏ⁾)/3
  2. x⁽⁰⁾ = (0, 0) → x⁽¹⁾ = (1.5, 8/3)
  3. x⁽²⁾ = (5/6, 5/3) → x⁽³⁾ = (13/12, 19/9)
  4. |4| > |1|; |3| > |2|; x⁽ᵏ⁾ → (1, 2)

Джерело: Авторська задача

Академічний 2

2x + y = 3.5; −x + 4y = 0.5; x⁽⁰⁾ = (2, 1); k = 2

Еталонний результат: x⁽¹⁾ = (1.25, 0.625); x⁽²⁾ = (1.4375, 0.4375)

Кроки обчислення
  1. x⁽ᵏ⁺¹⁾ = (3.5 − y⁽ᵏ⁾)/2; y⁽ᵏ⁺¹⁾ = (0.5 + x⁽ᵏ⁾)/4
  2. x⁽¹⁾ = (1.25, 0.625)
  3. x⁽²⁾ = (1.4375, 0.4375)

Джерело: COMP2421 Numerical Computation

Поглиблений 3

2·10⁻¹²x + 10⁻¹²y = 3·10⁻¹²; 10⁻¹²x + 2·10⁻¹²y = 3·10⁻¹²

Еталонний результат: x ≈ (1, 1); k > 1

Абсолютна нев’язка може дати хибну збіжність; тут допомагають відносні критерії.

Джерело: Авторська задача

Точність і типові помилки

Одночасне оновлення використовує лише попереднє наближення. Відносна нев’язка й крок не гарантують прямої похибки.
