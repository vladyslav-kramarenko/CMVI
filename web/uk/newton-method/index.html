Метод Ньютона

Знаходьте корені нелінійних рівнянь із заданою або чисельною похідною, дотичними та діагностикою збіжності.

Калькулятор

Завантажте задачу й натисніть «Розв’язати», щоб побачити кроки. Деякі поглиблені приклади навмисно не розв’язуються цим методом або розбігаються.

Приклад завантажено. Натисніть «Розв’язати».

Метод і умови застосовності

Метод Ньютона

xk+1=xk−f(xk)f′(xk)

Збіжність Ньютона залежить від початкового наближення, гладкості та ненульової похідної біля простого кореня.

Зупинка, коли абсолютний крок і нев’язка задовольняють свої допуски. Мала нев’язка сама по собі не обмежує похибку кореня.

Результати

Звіт про розв’язання

Розв’язані приклади

Базовий 1

f(x) = x² − 2; x₀ = 1

Еталонний результат: x ≈ 1.41421356237

Кроки обчислення
  1. f′(x) = 2x; xₖ₊₁ = (xₖ + 2/xₖ)/2
  2. x₀ = 1 → x₁ = 1.5 → x₂ = 17/12
  3. x₃ = 577/408 ≈ 1.414215686
  4. x ≈ 1.41421356237; |x² − 2| ≈ 0

Джерело: Авторська задача

Академічний 2

cos(x) + 2sin(x) + x² = 0; x₀ = 0; ε = 0.001

Еталонний результат: x₄ ≈ −0.6598

Кроки обчислення
  1. f′(x) = −sin(x) + 2cos(x) + 2x
  2. x₁ = 0 − 1/2 = −0.5
  3. x₂ ≈ −0.6368; x₃ ≈ −0.6589; x₄ ≈ −0.6598

Значення джерела округлено; порівнюйте з указаним допуском.

Джерело: University of Waterloo · Topic 10.3

Поглиблений 3

x² + 1 = 0; x₀ = 0

Еталонний результат: f′(0) = 0

Очікується зупинка: похідна нульова, крок Ньютона неможливий.

Джерело: Авторська задача

Точність і типові помилки

Невдале початкове наближення, кратний корінь або майже нульова похідна можуть завадити збіжності. Локальна оцінка лише орієнтир.
