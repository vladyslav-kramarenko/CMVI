Обернена матриця

Знаходьте обернену матрицю методом Гауса — Жордана, переглядайте проміжні матриці та чисельний ранг.

Калькулятор

Завантажте задачу й натисніть «Розв’язати», щоб побачити кроки. Деякі поглиблені приклади навмисно не розв’язуються цим методом або розбігаються.

Приклад завантажено. Натисніть «Розв’язати».

Метод і умови застосовності

Обернена матриця

[A|I]→[I|A−1]

Обернена матриця існує тоді й лише тоді, коли квадратна матриця невироджена. Майже вироджені матриці можуть мати неточно обчислену обернену.

Результати

Звіт про розв’язання

Розв’язані приклади

Базовий 1

A = [[4, 1], [2, 3]]

Еталонний результат: A⁻¹ = [[0.3, −0.1], [−0.2, 0.4]]

Кроки обчислення
  1. [A | I] = [4, 1 | 1, 0; 2, 3 | 0, 1]
  2. R₂ ← R₂ − ½R₁ → [0, 2.5 | −0.5, 1]
  3. R₂ / 2.5; R₁ ← (R₁ − R₂)/4
  4. [I | A⁻¹] = [1, 0 | 0.3, −0.1; 0, 1 | −0.2, 0.4]
  5. AA⁻¹ = I

Джерело: Авторська задача

Академічний 2

A = [[1, −1, 1], [2, 3, 0], [0, −2, 1]]

Еталонний результат: A⁻¹ = [[3, −1, −3], [−2, 1, 2], [−4, 2, 5]]

Кроки обчислення
  1. det(A) = 1
  2. [A | I] → [I | A⁻¹]
  3. AA⁻¹ = I

Джерело: Los Angeles City College · LibreTexts §2.4

Поглиблений 3

A = diag(1, 10⁻¹²)

Еталонний результат: A⁻¹ = diag(1, 10¹²); κ∞ = 10¹²

Обернена матриця може існувати попри погану обумовленість.

Джерело: Авторська задача

Точність і типові помилки

Перевіряйте AA⁻¹ − I та обумовленість. Мала нев’язка сама по собі не гарантує прямої точності.
