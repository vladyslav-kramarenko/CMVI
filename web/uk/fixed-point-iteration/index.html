Метод простої ітерації

Розв’язуйте x = g(x) послідовними наближеннями з діаграмою Кобвеба та оцінкою локальної похідної.

Калькулятор

Завантажте задачу й натисніть «Розв’язати», щоб побачити кроки. Деякі поглиблені приклади навмисно не розв’язуються цим методом або розбігаються.

Приклад завантажено. Натисніть «Розв’язати».

Метод і умови застосовності

Метод простої ітерації

xk+1=g(xk)

Для гарантії збіжності на інтервалі g має відображати його в себе і задовольняти |g′(x)| ≤ q < 1 на всьому інтервалі.

Похідна в обчисленій точці — лише локальна діагностика, а не доведення на інтервалі.

Результати

Звіт про розв’язання

Розв’язані приклади

Базовий 1

g(x) = cos(x); x₀ = 0.5

Еталонний результат: x ≈ 0.7390851332

Кроки обчислення
  1. xₖ₊₁ = cos(xₖ), x₀ = 0.5
  2. x₁ ≈ 0.877583; x₂ ≈ 0.639012; x₃ ≈ 0.802685
  3. g([0, 1]) ⊂ [0, 1]; |g′(x)| ≤ sin(1) < 1
  4. x ≈ 0.7390851332

Джерело: Авторська задача

Академічний 2

x² − 2 = 0; g(x) = x − (x² − 2)/3; x₀ = 1

Еталонний результат: x ≈ √2

Кроки обчислення
  1. x₁ = 4/3; x₂ = 38/27
  2. x₃ ≈ 1.413808871; x₄ ≈ 1.414190363

Джерело: G. Delius · Numerical Analysis, §3

Поглиблений 3

g(x) = x − (x² − 2); x₀ = 1; k = 8

Еталонний результат: 2, 0, 2, 0, 2, 0, 2, 0

Очікується цикл довжини два, а не збіжність.

Джерело: G. Delius · Numerical Analysis, §3

Точність і типові помилки

Строга межа похибки потребує відомої рівномірної константи стиску q < 1 на інваріантному інтервалі. Однієї похідної недостатньо.
