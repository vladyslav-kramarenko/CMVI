Метод простої ітерації

Розв’язуйте x = g(x) послідовними наближеннями з діаграмою Кобвеба та оцінкою локальної похідної.

Калькулятор

Метод і умови застосовності

Метод простої ітерації

xₖ₊₁ = g(xₖ)

Для гарантії збіжності на інтервалі g має відображати його в себе і задовольняти |g′(x)| ≤ q < 1 на всьому інтервалі.

Похідна в обчисленій точці — лише локальна діагностика, а не доведення на інтервалі.
