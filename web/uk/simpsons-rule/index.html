Метод Сімпсона

Обчислюйте визначені інтеграли за формулою Сімпсона з парною кількістю підінтервалів, уточненням сітки й оцінкою похибки.

Калькулятор

Метод і умови застосовності

Метод Сімпсона

Iₙ = (h/3)[f(x₀) + 4f(x₁) + 2f(x₂) + … + f(xₙ)]

Для достатньо гладкої f складена формула Сімпсона має порядок p = 4 і потребує парного n.

Задайте додатну цільову похибку для автоматичного уточнення сітки або 0 для збереження вихідної сітки.
