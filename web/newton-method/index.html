Method and applicability

Newton method

xk+1=xk−f(xk)f′(xk)

Newton convergence depends on the initial guess, smoothness and a nonzero derivative near a simple root.

Stop when both the absolute step and the residual satisfy their respective tolerances. A small residual alone does not bound root error.

Worked examples

Basic 1

f(x) = x² − 2; x₀ = 1

Expected result: x ≈ 1.41421356237

Calculation steps
  1. f′(x) = 2x; xₖ₊₁ = (xₖ + 2/xₖ)/2
  2. x₀ = 1 → x₁ = 1.5 → x₂ = 17/12
  3. x₃ = 577/408 ≈ 1.414215686
  4. x ≈ 1.41421356237; |x² − 2| ≈ 0

Academic 2

cos(x) + 2sin(x) + x² = 0; x₀ = 0; ε = 0.001

Expected result: x₄ ≈ −0.6598

Calculation steps
  1. f′(x) = −sin(x) + 2cos(x) + 2x
  2. x₁ = 0 − 1/2 = −0.5
  3. x₂ ≈ −0.6368; x₃ ≈ −0.6589; x₄ ≈ −0.6598

Source values are rounded; compare to the stated tolerance.

Source: University of Waterloo · Topic 10.3

Advanced 3

x² + 1 = 0; x₀ = 0

Expected result: f′(0) = 0

Expected: derivative is zero; a Newton step is unavailable.

Accuracy and common pitfalls

A poor starting point, multiple root or near-zero derivative may slow or prevent convergence. The local linearized error is only an indicator.
