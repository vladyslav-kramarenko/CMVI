Rechenbeispiele

Grundlagen 1

4x₁ + x₂ = 6; 2x₁ + 3x₂ = 8; x⁽⁰⁾ = (0, 0)

Erwartetes Ergebnis: x ≈ (1, 2)

Rechenschritte
  1. x₁⁽ᵏ⁺¹⁾ = (6 − x₂⁽ᵏ⁾)/4; x₂⁽ᵏ⁺¹⁾ = (8 − 2x₁⁽ᵏ⁾)/3
  2. x⁽⁰⁾ = (0, 0) → x⁽¹⁾ = (1.5, 8/3)
  3. x⁽²⁾ = (5/6, 5/3) → x⁽³⁾ = (13/12, 19/9)
  4. |4| > |1|; |3| > |2|; x⁽ᵏ⁾ → (1, 2)

Quelle: Eigene Aufgabe

Hochschule 2

2x + y = 3.5; −x + 4y = 0.5; x⁽⁰⁾ = (2, 1); k = 2

Erwartetes Ergebnis: x⁽¹⁾ = (1.25, 0.625); x⁽²⁾ = (1.4375, 0.4375)

Rechenschritte
  1. x⁽ᵏ⁺¹⁾ = (3.5 − y⁽ᵏ⁾)/2; y⁽ᵏ⁺¹⁾ = (0.5 + x⁽ᵏ⁾)/4
  2. x⁽¹⁾ = (1.25, 0.625)
  3. x⁽²⁾ = (1.4375, 0.4375)

Quelle: COMP2421 Numerical Computation

Fortgeschritten 3

2·10⁻¹²x + 10⁻¹²y = 3·10⁻¹²; 10⁻¹²x + 2·10⁻¹²y = 3·10⁻¹²

Erwartetes Ergebnis: x ≈ (1, 1); k > 1

Absolutes Residuum allein kann falsche Konvergenz melden; relative Kriterien vermeiden dies hier.

Genauigkeit und typische Fehler

Simultane Updates verwenden nur den vorherigen Iterierten. Relatives Residuum und Schritt sind keine Vorwärtsfehlergarantie.
