Jacobi-Verfahren

Gleichungssysteme mit Jacobi, Diagonaldominanzprüfung und Konvergenzdiagrammen lösen.

Methode und Anwendbarkeit

Jacobi-Iteration

xi(k+1)=bi−∑j≠iaijxj(k)aii

Alle Diagonalelemente müssen ungleich null sein. Strikte Zeilendiagonaldominanz ist hinreichend, nicht notwendig, für Konvergenz.

Ergebnisse

Lösungsbericht

Rechenbeispiel

4x₁ + x₂ = 6; 2x₁ + 3x₂ = 8; x⁽⁰⁾ = (0, 0) → x ≈ (1, 2)

Rechenschritte

  1. x₁⁽ᵏ⁺¹⁾ = (6 − x₂⁽ᵏ⁾)/4; x₂⁽ᵏ⁺¹⁾ = (8 − 2x₁⁽ᵏ⁾)/3
  2. x⁽⁰⁾ = (0, 0) → x⁽¹⁾ = (1.5, 8/3)
  3. x⁽²⁾ = (5/6, 5/3) → x⁽³⁾ = (13/12, 19/9)
  4. |4| > |1|; |3| > |2|; x⁽ᵏ⁾ → (1, 2)

Genauigkeit und typische Fehler

Simultane Updates verwenden nur den vorherigen Iterierten. Relatives Residuum und Schritt sind keine Vorwärtsfehlergarantie.
