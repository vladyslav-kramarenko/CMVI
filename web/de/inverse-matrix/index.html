Methode und Anwendbarkeit

Inverse Matrix

[A|I]→[I|A−1]

Eine Inverse existiert genau dann, wenn die quadratische Matrix regulär ist. Fast singuläre Matrizen können ungenaue Inversen liefern.

Rechenbeispiele

Grundlagen 1

A = [[4, 1], [2, 3]]

Erwartetes Ergebnis: A⁻¹ = [[0.3, −0.1], [−0.2, 0.4]]

Rechenschritte
  1. [A | I] = [4, 1 | 1, 0; 2, 3 | 0, 1]
  2. R₂ ← R₂ − ½R₁ → [0, 2.5 | −0.5, 1]
  3. R₂ / 2.5; R₁ ← (R₁ − R₂)/4
  4. [I | A⁻¹] = [1, 0 | 0.3, −0.1; 0, 1 | −0.2, 0.4]
  5. AA⁻¹ = I

Quelle: Eigene Aufgabe

Hochschule 2

A = [[1, −1, 1], [2, 3, 0], [0, −2, 1]]

Erwartetes Ergebnis: A⁻¹ = [[3, −1, −3], [−2, 1, 2], [−4, 2, 5]]

Rechenschritte
  1. det(A) = 1
  2. [A | I] → [I | A⁻¹]
  3. AA⁻¹ = I

Quelle: Los Angeles City College · LibreTexts §2.4

Fortgeschritten 3

A = diag(1, 10⁻¹²)

Erwartetes Ergebnis: A⁻¹ = diag(1, 10¹²); κ∞ = 10¹²

Eine Inverse kann trotz schlechter Kondition existieren.

Genauigkeit und typische Fehler

AA⁻¹ − I und Kondition prüfen. Ein kleines Prüfresiduum allein garantiert keine Vorwärtsgenauigkeit.
