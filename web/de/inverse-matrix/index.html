Inverse Matrix

Inverse Matrix mit Gauß-Jordan berechnen, Zwischenmatrizen und numerischen Rang prüfen.

Rechner

Methode und Anwendbarkeit

Inverse Matrix

[A|I]→[I|A−1]

Eine Inverse existiert genau dann, wenn die quadratische Matrix regulär ist. Fast singuläre Matrizen können ungenaue Inversen liefern.

Ergebnisse

Lösungsbericht

Rechenbeispiel

A = [[4, 1], [2, 3]] → A⁻¹ = (1/10)[[3, −1], [−2, 4]]

Rechenschritte

  1. [A | I] = [4, 1 | 1, 0; 2, 3 | 0, 1]
  2. R₂ ← R₂ − ½R₁ → [0, 2.5 | −0.5, 1]
  3. R₂ / 2.5; R₁ ← (R₁ − R₂)/4
  4. [I | A⁻¹] = [1, 0 | 0.3, −0.1; 0, 1 | −0.2, 0.4]
  5. AA⁻¹ = I

Genauigkeit und typische Fehler

AA⁻¹ − I und Kondition prüfen. Ein kleines Prüfresiduum allein garantiert keine Vorwärtsgenauigkeit.
