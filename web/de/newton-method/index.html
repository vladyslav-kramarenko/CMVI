Methode und Anwendbarkeit

Newton-Verfahren

xk+1=xk−f(xk)f′(xk)

Newton-Konvergenz hängt von Startwert, Glattheit und einer von null verschiedenen Ableitung nahe einer einfachen Nullstelle ab.

Abbruch, wenn absolute Schrittweite und Residuum ihre Toleranzen erfüllen. Ein kleines Residuum allein begrenzt den Nullstellenfehler nicht.

Lösungsbericht

Rechenbeispiele

Grundlagen 1

f(x) = x² − 2; x₀ = 1

Erwartetes Ergebnis: x ≈ 1.41421356237

Rechenschritte
  1. f′(x) = 2x; xₖ₊₁ = (xₖ + 2/xₖ)/2
  2. x₀ = 1 → x₁ = 1.5 → x₂ = 17/12
  3. x₃ = 577/408 ≈ 1.414215686
  4. x ≈ 1.41421356237; |x² − 2| ≈ 0

Quelle: Eigene Aufgabe

Hochschule 2

cos(x) + 2sin(x) + x² = 0; x₀ = 0; ε = 0.001

Erwartetes Ergebnis: x₄ ≈ −0.6598

Rechenschritte
  1. f′(x) = −sin(x) + 2cos(x) + 2x
  2. x₁ = 0 − 1/2 = −0.5
  3. x₂ ≈ −0.6368; x₃ ≈ −0.6589; x₄ ≈ −0.6598

Quellwerte sind gerundet; angegebene Toleranz beachten.

Quelle: University of Waterloo · Topic 10.3

Fortgeschritten 3

x² + 1 = 0; x₀ = 0

Erwartetes Ergebnis: f′(0) = 0

Erwarteter Abbruch: Ableitung null, Newton-Schritt unmöglich.

Genauigkeit und typische Fehler

Schlechter Startwert, mehrfache Nullstelle oder fast verschwindende Ableitung können Konvergenz verhindern. Lokaler Fehler ist nur ein Indikator.
