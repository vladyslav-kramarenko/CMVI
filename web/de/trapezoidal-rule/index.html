Trapezregel

Bestimmte Integrale mit zusammengesetzter Trapezregel, Gitterverfeinerung und Runge-Fehlerschätzung annähern.

Methode und Anwendbarkeit

Trapezregel

In=h[f(a)2+∑i=1n−1f(a+ih)+f(b)2]

Für hinreichend glattes f hat die zusammengesetzte Trapezregel Ordnung p = 2.

Positiven Zielfehler zur automatischen Verfeinerung eingeben, oder 0 für das vorgegebene Gitter.

Rechenbeispiele

Grundlagen 1

∫₀¹ x² dx; n = 4

Erwartetes Ergebnis: I₄ = 0.34375; I = 1/3

Rechenschritte
  1. h = 1/4; f(0) = 0; f(1/4) = 1/16; f(1/2) = 1/4; f(3/4) = 9/16; f(1) = 1
  2. I₄ = (1/4)(0 + 1/16 + 1/4 + 9/16 + 1/2) = 11/32
  3. I₈ = 43/128; |I₈ − I₄|/3 = 1/384
  4. |I₄ − 1/3| = 1/96

Quelle: Eigene Aufgabe

Hochschule 2

∫₁² x³ dx; n = 4

Erwartetes Ergebnis: I₄ = 3.796875; I = 3.75

Rechenschritte
  1. h = 1/4
  2. I₄ = ¼[½ + (5/4)³ + (3/2)³ + (7/4)³ + 4]

Quelle: University of Waterloo · Topic 13.2

Hochschule 3

∫₁² x³ dx; n = 8

Erwartetes Ergebnis: I₈ = 3.76171875

Rechenschritte
  1. h = 1/8; I₈ = 3.76171875
  2. |I₈ − I₄|/3 = 0.01171875

Quelle: University of Waterloo · Topic 13.2

Fortgeschritten 4

∫₀¹ cos(128πx) dx; n₀ = 4; ε = 10⁻⁶

Erwartetes Ergebnis: I = 0; |Iₙ| ≤ 10⁻⁶

Anfängliche dyadische Gitter verschleiern die Schwingung; das unabhängige Gitter zeigt die Abweichung.

Quelle: Eigene Aufgabe

Genauigkeit und typische Fehler

Für f ∈ C²[a,b] gilt die Schranke (b−a)h² max|f″|/12. Runge und unabhängige Gitter beweisen die Ableitungsschranke nicht.
