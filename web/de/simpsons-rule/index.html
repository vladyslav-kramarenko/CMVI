Methode und Anwendbarkeit

Simpsonregel

In=h3[f(x0)+4f(x1)+2f(x2)+…+f(xn)]

Für hinreichend glattes f hat die zusammengesetzte Simpsonregel Ordnung p = 4 und erfordert gerades n.

Positiven Zielfehler zur automatischen Verfeinerung eingeben, oder 0 für das vorgegebene Gitter.

Rechenbeispiele

Grundlagen 1

∫₀¹ x² dx; n = 4

Erwartetes Ergebnis: I₄ = 1/3

Rechenschritte
  1. h = 1/4; f(x) = x²
  2. I₄ = (1/12)[0 + 4(1/16) + 2(1/4) + 4(9/16) + 1]
  3. I₄ = (1/12) · 4 = 1/3
  4. I₈ = I₄; |I₈ − I₄|/15 = 0

Genauigkeit und typische Fehler

Für f ∈ C⁴[a,b] und gerades n gilt (b−a)h⁴ max|f⁽⁴⁾|/180. Kubische Polynome werden in exakter Arithmetik exakt integriert.
