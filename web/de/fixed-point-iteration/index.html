Methode und Anwendbarkeit

Fixpunktiteration

xk+1=g(xk)

Für Konvergenzgarantie muss g das Intervall in sich abbilden und überall |g′(x)| ≤ q < 1 erfüllen.

Die Ableitung am berechneten Punkt ist nur ein lokaler Hinweis, kein Intervallbeweis.

Rechenbeispiele

Grundlagen 1

g(x) = cos(x); x₀ = 0.5

Erwartetes Ergebnis: x ≈ 0.7390851332

Rechenschritte
  1. xₖ₊₁ = cos(xₖ), x₀ = 0.5
  2. x₁ ≈ 0.877583; x₂ ≈ 0.639012; x₃ ≈ 0.802685
  3. g([0, 1]) ⊂ [0, 1]; |g′(x)| ≤ sin(1) < 1
  4. x ≈ 0.7390851332

Quelle: Eigene Aufgabe

Hochschule 2

x² − 2 = 0; g(x) = x − (x² − 2)/3; x₀ = 1

Erwartetes Ergebnis: x ≈ √2

Rechenschritte
  1. x₁ = 4/3; x₂ = 38/27
  2. x₃ ≈ 1.413808871; x₄ ≈ 1.414190363

Quelle: G. Delius · Numerical Analysis, §3

Fortgeschritten 3

g(x) = x − (x² − 2); x₀ = 1; k = 8

Erwartetes Ergebnis: 2, 0, 2, 0, 2, 0, 2, 0

Zweierzyklus erwartet, keine Konvergenz.

Quelle: G. Delius · Numerical Analysis, §3

Genauigkeit und typische Fehler

Eine strenge Fehlerschranke erfordert eine uniforme Kontraktionskonstante q < 1 auf einem invarianten Intervall. Eine punktuelle Ableitung reicht nicht.
