Rechenbeispiele

Grundlagen 1

y″ = −2; y(0) = y(1) = 0

Erwartetes Ergebnis: y = (0, 1/4, 0)

Rechenschritte
  1. n = 2; h = 1/2; y₀ = y₂ = 0
  2. 4y₀ − 8y₁ + 4y₂ = −2
  3. y₁ = 1/4; (y₀, y₁, y₂) = (0, 1/4, 0)
  4. y(x) = x(1 − x); y″ = −2

Quelle: Eigene Aufgabe

Hochschule 2

T″ − 166(T − 293) = 0; T(0) = 473; T(0.1) = 293; n = 5

Erwartetes Ergebnis: T ≈ (473, 424.455861, 384.640390, 350.909842, 321.024507, 293) K

Rechenschritte
  1. h = 0.02; 2500Tᵢ₋₁ − 5166Tᵢ + 2500Tᵢ₊₁ = −48638
  2. T₀ = 473; T₅ = 293

Aufgabe der TU Delft; Referenzknotenwerte unabhängig für diese Diskretisierung berechnet.

Quelle: TU Delft · MUDE §2.9

Fortgeschritten 3

y″ = 0; y′(0) + 2y(0) = 1; y(1) = 0; n = 2

Erwartetes Ergebnis: y(x) = 1 − x; d₀ = 0

Rechenschritte
  1. y(x) = 1 − x → y′(0) + 2y(0) = 1
  2. d₀ = 2 − 1/h = 0

Randwertproblem lösbar, aber Thomas ohne Pivotisierung kann nicht fortfahren.

Quelle: Eigene Aufgabe

Genauigkeit und typische Fehler

Ein Nullpivot kann auch bei lösbaren Randwertproblemen auftreten. Diskrete Residuen und Gitterdifferenzen messen verschiedene Genauigkeitsaspekte.
