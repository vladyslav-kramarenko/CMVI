Worked example

4x₁ + x₂ = 6; 2x₁ + 3x₂ = 8; x⁽⁰⁾ = (0, 0) → x⁽¹⁾ = (1.5, 5/3) → x ≈ (1, 2)

Calculation steps

  1. x₁⁽ᵏ⁺¹⁾ = (6 − x₂⁽ᵏ⁾)/4; x₂⁽ᵏ⁺¹⁾ = (8 − 2x₁⁽ᵏ⁺¹⁾)/3
  2. x⁽⁰⁾ = (0, 0) → x⁽¹⁾ = (1.5, 5/3)
  3. x⁽²⁾ = (13/12, 35/18)
  4. |4| > |1|; |3| > |2|; x⁽ᵏ⁾ → (1, 2)

Accuracy and common pitfalls

Use newly computed components immediately. Changing the equation order can change convergence behavior.
