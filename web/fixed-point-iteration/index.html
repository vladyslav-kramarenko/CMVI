Method and applicability

Fixed-point iteration

xk+1=g(xk)

For a convergence guarantee on an interval, g must map the interval into itself and satisfy |g′(x)| ≤ q < 1 throughout it.

The derivative at the computed point is only a local diagnostic, not an interval-wide proof.

Worked examples

Basic 1

g(x) = cos(x); x₀ = 0.5

Expected result: x ≈ 0.7390851332

Calculation steps
  1. xₖ₊₁ = cos(xₖ), x₀ = 0.5
  2. x₁ ≈ 0.877583; x₂ ≈ 0.639012; x₃ ≈ 0.802685
  3. g([0, 1]) ⊂ [0, 1]; |g′(x)| ≤ sin(1) < 1
  4. x ≈ 0.7390851332

Academic 2

x² − 2 = 0; g(x) = x − (x² − 2)/3; x₀ = 1

Expected result: x ≈ √2

Calculation steps
  1. x₁ = 4/3; x₂ = 38/27
  2. x₃ ≈ 1.413808871; x₄ ≈ 1.414190363

Source: G. Delius · Numerical Analysis, §3

Advanced 3

g(x) = x − (x² − 2); x₀ = 1; k = 8

Expected result: 2, 0, 2, 0, 2, 0, 2, 0

Expected: a two-cycle, not convergence.

Source: G. Delius · Numerical Analysis, §3

Accuracy and common pitfalls

A rigorous error bound needs a known uniform contraction constant q < 1 on an invariant interval. A derivative at one point is not enough.
