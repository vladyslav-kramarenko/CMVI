Method and applicability

Inverse matrix

[A|I]→[I|A−1]

An inverse exists exactly when a square matrix is nonsingular. Near-singular matrices can have inaccurate inverses.

Worked examples

Basic 1

A = [[4, 1], [2, 3]]

Expected result: A⁻¹ = [[0.3, −0.1], [−0.2, 0.4]]

Calculation steps
  1. [A | I] = [4, 1 | 1, 0; 2, 3 | 0, 1]
  2. R₂ ← R₂ − ½R₁ → [0, 2.5 | −0.5, 1]
  3. R₂ / 2.5; R₁ ← (R₁ − R₂)/4
  4. [I | A⁻¹] = [1, 0 | 0.3, −0.1; 0, 1 | −0.2, 0.4]
  5. AA⁻¹ = I

Academic 2

A = [[1, −1, 1], [2, 3, 0], [0, −2, 1]]

Expected result: A⁻¹ = [[3, −1, −3], [−2, 1, 2], [−4, 2, 5]]

Calculation steps
  1. det(A) = 1
  2. [A | I] → [I | A⁻¹]
  3. AA⁻¹ = I

Source: Los Angeles City College · LibreTexts §2.4

Advanced 3

A = diag(1, 10⁻¹²)

Expected result: A⁻¹ = diag(1, 10¹²); κ∞ = 10¹²

Accuracy and common pitfalls

Check AA⁻¹ − I and conditioning. A small verification residual alone does not certify forward accuracy.
