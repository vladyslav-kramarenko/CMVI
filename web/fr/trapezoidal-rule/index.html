Méthode des trapèzes

Approchez les intégrales définies par trapèzes composites, raffinement de grille et estimation de Runge.

Calculateur

Chargez le problème, puis lancez le calcul. Certains exemples avancés échouent ou divergent volontairement.

Exemple chargé. Lancez le calcul.

Méthode et conditions d’application

Méthode des trapèzes

In=h[f(a)2+∑i=1n−1f(a+ih)+f(b)2]

Pour f suffisamment régulière, la méthode composite des trapèzes est d’ordre p = 2.

Indiquez une erreur cible positive pour raffiner automatiquement la grille, ou 0 pour conserver la grille demandée.

Exemples résolus

Débutant 1

∫₀¹ x² dx; n = 4

Résultat attendu: I₄ = 0.34375; I = 1/3

Étapes de calcul
  1. h = 1/4; f(0) = 0; f(1/4) = 1/16; f(1/2) = 1/4; f(3/4) = 9/16; f(1) = 1
  2. I₄ = (1/4)(0 + 1/16 + 1/4 + 9/16 + 1/2) = 11/32
  3. I₈ = 43/128; |I₈ − I₄|/3 = 1/384
  4. |I₄ − 1/3| = 1/96

Source: Exercice original

Universitaire 2

∫₁² x³ dx; n = 4

Résultat attendu: I₄ = 3.796875; I = 3.75

Étapes de calcul
  1. h = 1/4
  2. I₄ = ¼[½ + (5/4)³ + (3/2)³ + (7/4)³ + 4]

Source: University of Waterloo · Topic 13.2

Universitaire 3

∫₁² x³ dx; n = 8

Résultat attendu: I₈ = 3.76171875

Étapes de calcul
  1. h = 1/8; I₈ = 3.76171875
  2. |I₈ − I₄|/3 = 0.01171875

Source: University of Waterloo · Topic 13.2

Avancé 4

∫₀¹ cos(128πx) dx; n₀ = 4; ε = 10⁻⁶

Résultat attendu: I = 0; |Iₙ| ≤ 10⁻⁶

Les grilles dyadiques initiales masquent l’oscillation ; la grille indépendante révèle l’écart.

Source: Exercice original

Précision et erreurs fréquentes

Pour f ∈ C²[a,b], une borne est (b−a)h² max|f″|/12. Runge et grilles indépendantes ne prouvent pas cette borne de dérivée.
