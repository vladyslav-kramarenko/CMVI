Exemples résolus

Débutant 1

y″ = −2; y(0) = y(1) = 0

Résultat attendu: y = (0, 1/4, 0)

Étapes de calcul
  1. n = 2; h = 1/2; y₀ = y₂ = 0
  2. 4y₀ − 8y₁ + 4y₂ = −2
  3. y₁ = 1/4; (y₀, y₁, y₂) = (0, 1/4, 0)
  4. y(x) = x(1 − x); y″ = −2

Source: Exercice original

Universitaire 2

T″ − 166(T − 293) = 0; T(0) = 473; T(0.1) = 293; n = 5

Résultat attendu: T ≈ (473, 424.455861, 384.640390, 350.909842, 321.024507, 293) K

Étapes de calcul
  1. h = 0.02; 2500Tᵢ₋₁ − 5166Tᵢ + 2500Tᵢ₊₁ = −48638
  2. T₀ = 473; T₅ = 293

Problème de TU Delft ; valeurs nodales de référence calculées indépendamment.

Source: TU Delft · MUDE §2.9

Avancé 3

y″ = 0; y′(0) + 2y(0) = 1; y(1) = 0; n = 2

Résultat attendu: y(x) = 1 − x; d₀ = 0

Étapes de calcul
  1. y(x) = 1 − x → y′(0) + 2y(0) = 1
  2. d₀ = 2 − 1/h = 0

Le problème est résoluble, mais Thomas sans pivot ne peut continuer.

Source: Exercice original

Précision et erreurs fréquentes

Un pivot nul peut apparaître même pour un problème aux limites résoluble. Résidus discrets et différences de maillage mesurent des aspects différents.
