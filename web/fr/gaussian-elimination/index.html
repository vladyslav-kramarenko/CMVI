Méthode de Gauss

Résolvez des systèmes linéaires par Gauss-Jordan avec pivot partiel et vérification du résidu.

Calculateur

Méthode et conditions d’application

Élimination de Gauss-Jordan

[A|b]→[I|x]

Un système carré Ax = b a une solution unique si A est inversible.

Le pivot partiel réduit certaines erreurs d’arrondi sans éliminer le mauvais conditionnement.

Résultats

Rapport de résolution

Exemple résolu

4x₁ + x₂ = 6; 2x₁ + 3x₂ = 8 → x₁ = 1, x₂ = 2

Étapes de calcul

  1. [4, 1 | 6; 2, 3 | 8] → R₂ − ½R₁ → [4, 1 | 6; 0, 2.5 | 5]
  2. R₂ / 2.5 → [0, 1 | 2]
  3. R₁ − R₂ → [4, 0 | 4] → R₁ / 4 → [1, 0 | 1]
  4. Ax − b = (0, 0)

Précision et erreurs fréquentes

Un petit résidu ne garantit pas une solution précise si la matrice est mal conditionnée ; examinez l’erreur rétrograde et le conditionnement.
