Méthode de Jacobi

Résolvez des systèmes par Jacobi avec diagnostic de dominance diagonale et courbe de convergence.

Calculateur

Chargez le problème, puis lancez le calcul. Certains exemples avancés échouent ou divergent volontairement.

Exemple chargé. Lancez le calcul.

Méthode et conditions d’application

Itération de Jacobi

xi(k+1)=bi−∑j≠iaijxj(k)aii

Les éléments diagonaux doivent être non nuls. La dominance diagonale stricte par lignes est suffisante, non nécessaire, pour la convergence.

Exemples résolus

Débutant 1

4x₁ + x₂ = 6; 2x₁ + 3x₂ = 8; x⁽⁰⁾ = (0, 0)

Résultat attendu: x ≈ (1, 2)

Étapes de calcul
  1. x₁⁽ᵏ⁺¹⁾ = (6 − x₂⁽ᵏ⁾)/4; x₂⁽ᵏ⁺¹⁾ = (8 − 2x₁⁽ᵏ⁾)/3
  2. x⁽⁰⁾ = (0, 0) → x⁽¹⁾ = (1.5, 8/3)
  3. x⁽²⁾ = (5/6, 5/3) → x⁽³⁾ = (13/12, 19/9)
  4. |4| > |1|; |3| > |2|; x⁽ᵏ⁾ → (1, 2)

Source: Exercice original

Universitaire 2

2x + y = 3.5; −x + 4y = 0.5; x⁽⁰⁾ = (2, 1); k = 2

Résultat attendu: x⁽¹⁾ = (1.25, 0.625); x⁽²⁾ = (1.4375, 0.4375)

Étapes de calcul
  1. x⁽ᵏ⁺¹⁾ = (3.5 − y⁽ᵏ⁾)/2; y⁽ᵏ⁺¹⁾ = (0.5 + x⁽ᵏ⁾)/4
  2. x⁽¹⁾ = (1.25, 0.625)
  3. x⁽²⁾ = (1.4375, 0.4375)

Source: COMP2421 Numerical Computation

Avancé 3

2·10⁻¹²x + 10⁻¹²y = 3·10⁻¹²; 10⁻¹²x + 2·10⁻¹²y = 3·10⁻¹²

Résultat attendu: x ≈ (1, 1); k > 1

Le résidu absolu seul peut indiquer une fausse convergence ; les critères relatifs l’évitent ici.

Source: Exercice original

Précision et erreurs fréquentes

Les mises à jour simultanées utilisent uniquement l’itération précédente. Résidu et pas relatifs ne garantissent pas l’erreur directe.
