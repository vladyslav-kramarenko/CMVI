Méthode de Simpson

Approchez les intégrales définies par interpolation parabolique, subdivisions paires, raffinement et estimation d’erreur.

Méthode et conditions d’application

Méthode de Simpson

In=h3[f(x0)+4f(x1)+2f(x2)+…+f(xn)]

Pour f suffisamment régulière, la méthode composite de Simpson est d’ordre p = 4 et exige n pair.

Indiquez une erreur cible positive pour raffiner automatiquement la grille, ou 0 pour conserver la grille demandée.

Résultats

Rapport de résolution

Exemple résolu

∫₀¹ x² dx; n = 4 → I₄ = 1/3

Étapes de calcul

  1. h = 1/4; f(x) = x²
  2. I₄ = (1/12)[0 + 4(1/16) + 2(1/4) + 4(9/16) + 1]
  3. I₄ = (1/12) · 4 = 1/3
  4. I₈ = I₄; |I₈ − I₄|/15 = 0

Précision et erreurs fréquentes

Pour f ∈ C⁴[a,b] et n pair, l’erreur est bornée par (b−a)h⁴ max|f⁽⁴⁾|/180. Les polynômes cubiques sont intégrés exactement en arithmétique exacte.
