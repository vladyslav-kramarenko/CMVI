Itération du point fixe

Résolvez x = g(x) par approximations successives, diagrammes en toile d’araignée et dérivée locale.

Calculateur

Chargez le problème, puis lancez le calcul. Certains exemples avancés échouent ou divergent volontairement.

Exemple chargé. Lancez le calcul.

Méthode et conditions d’application

Itération du point fixe

xk+1=g(xk)

Pour garantir la convergence sur un intervalle, g doit le préserver et vérifier |g′(x)| ≤ q < 1 partout.

La dérivée au point calculé est un diagnostic local, pas une preuve sur l’intervalle.

Exemples résolus

Débutant 1

g(x) = cos(x); x₀ = 0.5

Résultat attendu: x ≈ 0.7390851332

Étapes de calcul
  1. xₖ₊₁ = cos(xₖ), x₀ = 0.5
  2. x₁ ≈ 0.877583; x₂ ≈ 0.639012; x₃ ≈ 0.802685
  3. g([0, 1]) ⊂ [0, 1]; |g′(x)| ≤ sin(1) < 1
  4. x ≈ 0.7390851332

Source: Exercice original

Universitaire 2

x² − 2 = 0; g(x) = x − (x² − 2)/3; x₀ = 1

Résultat attendu: x ≈ √2

Étapes de calcul
  1. x₁ = 4/3; x₂ = 38/27
  2. x₃ ≈ 1.413808871; x₄ ≈ 1.414190363

Source: G. Delius · Numerical Analysis, §3

Avancé 3

g(x) = x − (x² − 2); x₀ = 1; k = 8

Résultat attendu: 2, 0, 2, 0, 2, 0, 2, 0

Cycle de période deux attendu, pas de convergence.

Source: G. Delius · Numerical Analysis, §3

Précision et erreurs fréquentes

Une borne rigoureuse exige une constante uniforme q < 1 sur un intervalle invariant. Une dérivée ponctuelle ne suffit pas.
