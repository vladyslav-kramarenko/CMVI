Метод трапеций

Приближённо вычисляйте определённые интегралы составной формулой трапеций с уточнением сетки и оценкой Рунге.

Калькулятор

Метод и условия применимости

Метод трапеций

Iₙ = h[f(a)/2 + Σᵢ₌₁ⁿ⁻¹ f(a + ih) + f(b)/2]

Для достаточно гладкой f составная формула трапеций имеет порядок p = 2.

Задайте положительную целевую погрешность для автоматического уточнения сетки или 0 для сохранения исходной сетки.
