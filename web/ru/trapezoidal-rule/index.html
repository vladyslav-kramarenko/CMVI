Метод трапеций

Приближённо вычисляйте определённые интегралы составной формулой трапеций с уточнением сетки и оценкой Рунге.

Калькулятор

Загрузите задачу и нажмите «Решить», чтобы увидеть шаги. Некоторые продвинутые примеры намеренно не решаются этим методом или не сходятся.

Пример загружен. Нажмите «Решить».

Метод и условия применимости

Метод трапеций

In=h[f(a)2+∑i=1n−1f(a+ih)+f(b)2]

Для достаточно гладкой f составная формула трапеций имеет порядок p = 2.

Задайте положительную целевую погрешность для автоматического уточнения сетки или 0 для сохранения исходной сетки.

Результаты

Отчёт о решении

Решённые примеры

Базовый 1

∫₀¹ x² dx; n = 4

Эталонный результат: I₄ = 0.34375; I = 1/3

Шаги вычисления
  1. h = 1/4; f(0) = 0; f(1/4) = 1/16; f(1/2) = 1/4; f(3/4) = 9/16; f(1) = 1
  2. I₄ = (1/4)(0 + 1/16 + 1/4 + 9/16 + 1/2) = 11/32
  3. I₈ = 43/128; |I₈ − I₄|/3 = 1/384
  4. |I₄ − 1/3| = 1/96

Источник: Авторская задача

Академический 2

∫₁² x³ dx; n = 4

Эталонный результат: I₄ = 3.796875; I = 3.75

Шаги вычисления
  1. h = 1/4
  2. I₄ = ¼[½ + (5/4)³ + (3/2)³ + (7/4)³ + 4]

Источник: University of Waterloo · Topic 13.2

Академический 3

∫₁² x³ dx; n = 8

Эталонный результат: I₈ = 3.76171875

Шаги вычисления
  1. h = 1/8; I₈ = 3.76171875
  2. |I₈ − I₄|/3 = 0.01171875

Источник: University of Waterloo · Topic 13.2

Продвинутый 4

∫₀¹ cos(128πx) dx; n₀ = 4; ε = 10⁻⁶

Эталонный результат: I = 0; |Iₙ| ≤ 10⁻⁶

Начальные двоичные сетки маскируют колебания; независимая сетка выявляет расхождение.

Источник: Авторская задача

Точность и типичные ошибки

Для f ∈ C²[a,b] граница погрешности составной формулы — (b−a)h² max|f″|/12. Оценка Рунге и независимые сетки не доказывают границу производной.
