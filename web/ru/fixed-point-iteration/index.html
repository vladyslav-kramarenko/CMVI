Метод простых итераций

Решайте x = g(x) последовательными приближениями с диаграммой Кобвеба и оценкой локальной производной.

Калькулятор

Метод и условия применимости

Метод простых итераций

xk+1=g(xk)

Для гарантии сходимости на интервале g должна отображать его в себя и удовлетворять |g′(x)| ≤ q < 1 на всём интервале.

Производная в вычисленной точке — лишь локальная диагностика, а не доказательство на интервале.

Результаты

Отчёт о решении

Пример решения

g(x) = cos(x); x₀ = 0.5 → x₁ ≈ 0.877583 → x ≈ 0.739085

Шаги вычисления

  1. xₖ₊₁ = cos(xₖ), x₀ = 0.5
  2. x₁ ≈ 0.877583; x₂ ≈ 0.639012; x₃ ≈ 0.802685
  3. g([0, 1]) ⊂ [0, 1]; |g′(x)| ≤ sin(1) < 1
  4. x ≈ 0.7390851332

Точность и типичные ошибки

Строгая граница ошибки требует известной равномерной константы сжатия q < 1 на инвариантном интервале. Производной в одной точке недостаточно.
