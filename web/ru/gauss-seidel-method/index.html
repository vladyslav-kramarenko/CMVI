Метод Гаусса — Зейделя

Изучайте последовательные обновления, условия сходимости и историю невязки при решении линейных систем.

Решённые примеры

Базовый 1

4x₁ + x₂ = 6; 2x₁ + 3x₂ = 8; x⁽⁰⁾ = (0, 0)

Эталонный результат: x ≈ (1, 2)

Шаги вычисления
  1. x₁⁽ᵏ⁺¹⁾ = (6 − x₂⁽ᵏ⁾)/4; x₂⁽ᵏ⁺¹⁾ = (8 − 2x₁⁽ᵏ⁺¹⁾)/3
  2. x⁽⁰⁾ = (0, 0) → x⁽¹⁾ = (1.5, 5/3)
  3. x⁽²⁾ = (13/12, 35/18)
  4. |4| > |1|; |3| > |2|; x⁽ᵏ⁾ → (1, 2)

Источник: Авторская задача

Академический 2

2x − y = 3; x + 3y = 1; x⁽⁰⁾ = (1, −1); k = 3

Эталонный результат: x⁽³⁾ = (17/12, −5/36)

Шаги вычисления
  1. x⁽ᵏ⁺¹⁾ = (3 + y⁽ᵏ⁾)/2; y⁽ᵏ⁺¹⁾ = (1 − x⁽ᵏ⁺¹⁾)/3
  2. x⁽¹⁾ = (1, 0); x⁽²⁾ = (3/2, −1/6)
  3. x⁽³⁾ = (17/12, −5/36)

Источник: Durham University · MATH1551, 1.13

Продвинутый 3

x + 2y = 3; 2x + y = 3; k = 8

Эталонный результат: x⁽¹⁾ = (3, −3); x⁽²⁾ = (9, −15)

Ожидается достижение лимита, а не сходимость.

Источник: Авторская задача

Точность и типичные ошибки

Новые компоненты используются сразу. Перестановка уравнений может изменить сходимость.
