Отчёт о решении

Пример решения

4x₁ + x₂ = 6; 2x₁ + 3x₂ = 8; x⁽⁰⁾ = (0, 0) → x ≈ (1, 2)

Шаги вычисления

  1. x₁⁽ᵏ⁺¹⁾ = (6 − x₂⁽ᵏ⁾)/4; x₂⁽ᵏ⁺¹⁾ = (8 − 2x₁⁽ᵏ⁾)/3
  2. x⁽⁰⁾ = (0, 0) → x⁽¹⁾ = (1.5, 8/3)
  3. x⁽²⁾ = (5/6, 5/3) → x⁽³⁾ = (13/12, 19/9)
  4. |4| > |1|; |3| > |2|; x⁽ᵏ⁾ → (1, 2)

Точность и типичные ошибки

Одновременное обновление использует только предыдущее приближение. Относительная невязка и шаг — критерии остановки, а не гарантия точности.
