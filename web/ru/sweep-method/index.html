Метод прогонки (алгоритм Томаса)

Решайте линейные краевые задачи второго порядка конечными разностями с условиями Робина и таблицами прогонки.

Калькулятор

Загрузите задачу и нажмите «Решить», чтобы увидеть шаги. Некоторые продвинутые примеры намеренно не решаются этим методом или не сходятся.

Пример загружен. Нажмите «Решить».

Метод и условия применимости

Метод прогонки (алгоритм Томаса)

liyi−1+diyi+uiyi+1=ri

Дискретизированная трёхдиагональная система должна допускать ненулевые ведущие элементы прогонки. На границах используются односторонние разности первого порядка.

Результаты

Отчёт о решении

Решённые примеры

Базовый 1

y″ = −2; y(0) = y(1) = 0

Эталонный результат: y = (0, 1/4, 0)

Шаги вычисления
  1. n = 2; h = 1/2; y₀ = y₂ = 0
  2. 4y₀ − 8y₁ + 4y₂ = −2
  3. y₁ = 1/4; (y₀, y₁, y₂) = (0, 1/4, 0)
  4. y(x) = x(1 − x); y″ = −2

Источник: Авторская задача

Академический 2

T″ − 166(T − 293) = 0; T(0) = 473; T(0.1) = 293; n = 5

Эталонный результат: T ≈ (473, 424.455861, 384.640390, 350.909842, 321.024507, 293) K

Шаги вычисления
  1. h = 0.02; 2500Tᵢ₋₁ − 5166Tᵢ + 2500Tᵢ₊₁ = −48638
  2. T₀ = 473; T₅ = 293

Задача из TU Delft; эталонные значения узлов независимо вычислены для этой дискретизации.

Источник: TU Delft · MUDE §2.9

Продвинутый 3

y″ = 0; y′(0) + 2y(0) = 1; y(1) = 0; n = 2

Эталонный результат: y(x) = 1 − x; d₀ = 0

Шаги вычисления
  1. y(x) = 1 − x → y′(0) + 2y(0) = 1
  2. d₀ = 2 − 1/h = 0

Краевая задача разрешима, но прогонка без выбора ведущего элемента не может продолжаться.

Источник: Авторская задача

Точность и типичные ошибки

Нулевой ведущий элемент прогонки возможен даже у разрешимой краевой задачи. Дискретная невязка и разность сеток измеряют разные аспекты точности.
