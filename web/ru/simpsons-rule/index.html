Метод Симпсона

Вычисляйте определённые интегралы по формуле Симпсона с чётным числом разбиений, уточнением сетки и оценкой погрешности.

Метод и условия применимости

Метод Симпсона

Iₙ = (h/3)[f(x₀) + 4f(x₁) + 2f(x₂) + … + f(xₙ)]

Для достаточно гладкой f составная формула Симпсона имеет порядок p = 4 и требует чётного n.

Задайте положительную целевую погрешность для автоматического уточнения сетки или 0 для сохранения исходной сетки.
