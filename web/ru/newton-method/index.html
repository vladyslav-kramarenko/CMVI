Метод Ньютона

Находите корни нелинейных уравнений с заданной или численной производной, касательными и диагностикой сходимости.

Калькулятор

Загрузите задачу и нажмите «Решить», чтобы увидеть шаги. Некоторые продвинутые примеры намеренно не решаются этим методом или не сходятся.

Пример загружен. Нажмите «Решить».

Метод и условия применимости

Метод Ньютона

xk+1=xk−f(xk)f′(xk)

Сходимость Ньютона зависит от начального приближения, гладкости и ненулевой производной около простого корня.

Остановка, когда абсолютный шаг и невязка удовлетворяют своим допускам. Малая невязка сама по себе не ограничивает погрешность корня.

Решённые примеры

Базовый 1

f(x) = x² − 2; x₀ = 1

Эталонный результат: x ≈ 1.41421356237

Шаги вычисления
  1. f′(x) = 2x; xₖ₊₁ = (xₖ + 2/xₖ)/2
  2. x₀ = 1 → x₁ = 1.5 → x₂ = 17/12
  3. x₃ = 577/408 ≈ 1.414215686
  4. x ≈ 1.41421356237; |x² − 2| ≈ 0

Источник: Авторская задача

Академический 2

cos(x) + 2sin(x) + x² = 0; x₀ = 0; ε = 0.001

Эталонный результат: x₄ ≈ −0.6598

Шаги вычисления
  1. f′(x) = −sin(x) + 2cos(x) + 2x
  2. x₁ = 0 − 1/2 = −0.5
  3. x₂ ≈ −0.6368; x₃ ≈ −0.6589; x₄ ≈ −0.6598

В источнике значения округлены; сравнивайте с указанным допуском.

Источник: University of Waterloo · Topic 10.3

Продвинутый 3

x² + 1 = 0; x₀ = 0

Эталонный результат: f′(0) = 0

Ожидается остановка: производная нулевая, шаг Ньютона невозможен.

Источник: Авторская задача

Точность и типичные ошибки

Неудачное начальное приближение, кратный корень или почти нулевая производная могут замедлить или нарушить сходимость. Локальная оценка ошибки лишь ориентир.
