Метод и условия применимости

Обратная матрица

[A|I]→[I|A−1]

Обратная матрица существует тогда и только тогда, когда квадратная матрица невырождена. Почти вырожденные матрицы могут иметь неточно вычисленную обратную.

Решённые примеры

Базовый 1

A = [[4, 1], [2, 3]]

Эталонный результат: A⁻¹ = [[0.3, −0.1], [−0.2, 0.4]]

Шаги вычисления
  1. [A | I] = [4, 1 | 1, 0; 2, 3 | 0, 1]
  2. R₂ ← R₂ − ½R₁ → [0, 2.5 | −0.5, 1]
  3. R₂ / 2.5; R₁ ← (R₁ − R₂)/4
  4. [I | A⁻¹] = [1, 0 | 0.3, −0.1; 0, 1 | −0.2, 0.4]
  5. AA⁻¹ = I

Источник: Авторская задача

Академический 2

A = [[1, −1, 1], [2, 3, 0], [0, −2, 1]]

Эталонный результат: A⁻¹ = [[3, −1, −3], [−2, 1, 2], [−4, 2, 5]]

Шаги вычисления
  1. det(A) = 1
  2. [A | I] → [I | A⁻¹]
  3. AA⁻¹ = I

Источник: Los Angeles City College · LibreTexts §2.4

Продвинутый 3

A = diag(1, 10⁻¹²)

Эталонный результат: A⁻¹ = diag(1, 10¹²); κ∞ = 10¹²

Обратная матрица может существовать даже при плохой обусловленности.

Источник: Авторская задача

Точность и типичные ошибки

Проверяйте AA⁻¹ − I и обусловленность. Малая невязка проверки сама по себе не гарантирует прямую точность.
