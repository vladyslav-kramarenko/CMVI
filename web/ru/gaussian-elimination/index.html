Метод Гаусса

Решайте системы линейных уравнений методом Гаусса — Жордана с выбором главного элемента и проверкой невязки.

Калькулятор

Загрузите задачу и нажмите «Решить», чтобы увидеть шаги. Некоторые продвинутые примеры намеренно не решаются этим методом или не сходятся.

Пример загружен. Нажмите «Решить».

Метод и условия применимости

Метод Гаусса — Жордана

[A|b]→[I|x]

Квадратная система Ax = b имеет единственное решение, если A невырождена.

Частичный выбор главного элемента уменьшает некоторые ошибки округления, но не устраняет плохую обусловленность.

Решённые примеры

Базовый 1

4x₁ + x₂ = 6; 2x₁ + 3x₂ = 8

Эталонный результат: x = (1, 2)

Шаги вычисления
  1. [4, 1 | 6; 2, 3 | 8] → R₂ − ½R₁ → [4, 1 | 6; 0, 2.5 | 5]
  2. R₂ / 2.5 → [0, 1 | 2]
  3. R₁ − R₂ → [4, 0 | 4] → R₁ / 4 → [1, 0 | 1]
  4. Ax − b = (0, 0)

Источник: Авторская задача

Академический 2

x + 3y = 7; 3x + 4y = 11

Эталонный результат: x = 1; y = 2

Шаги вычисления
  1. R₂ ← R₂ − 3R₁ → −5y = −10
  2. y = 2; x = 7 − 3y = 1

Источник: Los Angeles City College · LibreTexts §2.2

Продвинутый 3

x + 2y = 3; 2x + 4y = 7

Эталонный результат: rank(A) = 1; rank([A|b]) = 2

Шаги вычисления
  1. R₂ ← R₂ − 2R₁ → 0 = 1

Ожидается отказ: система несовместна, единственного решения нет.

Источник: Авторская задача

Точность и типичные ошибки

Малая невязка не гарантирует точное решение при плохой обусловленности; сравнивайте обратную погрешность и число обусловленности.
