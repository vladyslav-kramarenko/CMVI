Krylov method (Arnoldi–QR)

Compute characteristic polynomials, real and complex eigenvalues and verified eigenvectors using Krylov subspaces and shifted QR.

Calculator

Method and applicability

Krylov / Arnoldi–QR

Km(A,v)=span(v,Av,…,Am−1v)

The implementation uses restarted orthogonal Krylov chains and shifted QR. A single cyclic vector is not required.

Repeated eigenvalues need not have a complete eigenvector basis.

Results

Solution report

Worked example

A = [[4, 1], [2, 3]] → P(λ) = λ² − 7λ + 10 → λ₁ = 2, λ₂ = 5

Calculation steps

  1. v = (1, 0)ᵀ; Av = (4, 2)ᵀ; A²v = (18, 14)ᵀ
  2. A²v − 7Av + 10v = (0, 0)ᵀ
  3. P(λ) = λ² − 7λ + 10 = (λ − 2)(λ − 5)
  4. λ = 2: v = (−1, 2)ᵀ; λ = 5: v = (1, 1)ᵀ
  5. Av = λv

Accuracy and common pitfalls

The worked example uses the classical cyclic Krylov relation. The calculator instead builds an orthonormal Krylov basis and applies QR; close eigenvalues remain sensitive.
