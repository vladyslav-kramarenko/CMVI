Method and applicability

Jacobi iteration

xi(k+1)=bi−∑j≠iaijxj(k)aii

All diagonal entries must be nonzero. Strict row diagonal dominance is a sufficient, not necessary, convergence condition.

Worked examples

Basic 1

4x₁ + x₂ = 6; 2x₁ + 3x₂ = 8; x⁽⁰⁾ = (0, 0)

Expected result: x ≈ (1, 2)

Calculation steps
  1. x₁⁽ᵏ⁺¹⁾ = (6 − x₂⁽ᵏ⁾)/4; x₂⁽ᵏ⁺¹⁾ = (8 − 2x₁⁽ᵏ⁾)/3
  2. x⁽⁰⁾ = (0, 0) → x⁽¹⁾ = (1.5, 8/3)
  3. x⁽²⁾ = (5/6, 5/3) → x⁽³⁾ = (13/12, 19/9)
  4. |4| > |1|; |3| > |2|; x⁽ᵏ⁾ → (1, 2)

Academic 2

2x + y = 3.5; −x + 4y = 0.5; x⁽⁰⁾ = (2, 1); k = 2

Expected result: x⁽¹⁾ = (1.25, 0.625); x⁽²⁾ = (1.4375, 0.4375)

Calculation steps
  1. x⁽ᵏ⁺¹⁾ = (3.5 − y⁽ᵏ⁾)/2; y⁽ᵏ⁺¹⁾ = (0.5 + x⁽ᵏ⁾)/4
  2. x⁽¹⁾ = (1.25, 0.625)
  3. x⁽²⁾ = (1.4375, 0.4375)

Source: COMP2421 Numerical Computation

Advanced 3

2·10⁻¹²x + 10⁻¹²y = 3·10⁻¹²; 10⁻¹²x + 2·10⁻¹²y = 3·10⁻¹²

Expected result: x ≈ (1, 1); k > 1

Absolute residual alone can give false convergence; relative diagnostics avoid that in this example.

Source: Original exercise

Accuracy and common pitfalls

Simultaneous updates use only the previous iterate. Relative residual and relative step are stopping diagnostics, not forward-error guarantees.
