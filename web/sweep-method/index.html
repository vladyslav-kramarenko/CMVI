Method and applicability

Sweep method (Thomas algorithm)

liyi−1+diyi+uiyi+1=ri

The discretized tridiagonal system must admit nonzero sweep pivots. Boundary derivatives use first-order one-sided differences.

Worked example

y″ = −2; y(0) = y(1) = 0 → y(x) = x(1 − x)

Calculation steps

  1. n = 2; h = 1/2; y₀ = y₂ = 0
  2. 4y₀ − 8y₁ + 4y₂ = −2
  3. y₁ = 1/4; (y₀, y₁, y₂) = (0, 1/4, 0)
  4. y(x) = x(1 − x); y″ = −2

Accuracy and common pitfalls

A zero sweep pivot can occur even for a solvable boundary-value problem. Discrete residuals and mesh differences measure different aspects of accuracy.
